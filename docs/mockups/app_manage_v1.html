앱 아이콘 — 지연 로딩 · 디스크 캐시

목록은 패키지명 해시 타일로 즉시 뜨고, 실제 아이콘은 행이 보일 때만 기기 APK에서 뽑아 채웁니다. 128개를 한꺼번에 pull하면 기가바이트 단위가 되므로 기본은 동시 2 · 30일 캐시입니다.

아이콘 파이프라인

① 기본 타일
목록 즉시 표시. 패키지명 해시로 색을 고정해 스크롤해도 같은 앱은 같은 색.
보이는 행만
② 추출 중
APK pull → 리소스 해석. 행은 shimmer로 자리만 잡고 목록을 막지 않는다.
1.2 s
③ 실제 아이콘
기기에서 뽑은 128px PNG/WebP. 캐시 키 = pkg + versionCode 라 업데이트하면 자동 갱신.
↻ 재시도
④ 실패
빈칸으로 두지 않는다 — 기본 타일 유지 + 사유는 로그에만. 다음 스크롤에 재시도.
pm path <pkg>→ adb pull base.apk→ ZIP + resources.arsc→ 128px PNG→ ~/Library/Caches/…/icons
APK 1개가 20~200MB입니다. 전체 일괄 추출은 금지. 아이콘 토글을 끄면 pull 자체를 하지 않으며, 실패·미지원(어댑티브 아이콘만 있는 앱)은 기본 타일로 남습니다.
읽기 전용 경계 유지

설치·삭제는 사용자가 명시한 동작에만. MCP 도구·감시 엔진·자동 재연결 경로에서는 호출 불가. DECISIONS D6로 못 박습니다.

기기 설정은 건드리지 않음

Play 프로텍트·설치 검증을 settings put으로 끄지 않습니다. 차단되면 원인과 해제 방법만 안내. -g(권한 자동 허용)도 기본 OFF.

모든 동작은 감사 가능하게

파일명·SHA-256·대상 기기·adb 원문 코드·확인된 버전을 IssueLog에 기록. 경로는 ~/로 축약해 개인정보 노출을 막습니다.
